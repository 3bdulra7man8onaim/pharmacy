# 💊 صيدلية هشام - نظام إدارة صيدلية متكامل

## 📋 نظرة عامة

نظام إدارة صيدلية شامل يتكون من ثلاث منصات رئيسية:
1. **صفحة العميل (Client)** - واجهة التسوق والطلبات
2. **لوحة الإدارة (Admin)** - إدارة المنتجات والطلبات
3. **الدكتور AI** - مساعد طبي ذكي للاستشارات

## 🎯 المميزات الرئيسية

### 1️⃣ صفحة العميل (Client Interface)

#### 🏠 الصفحة الرئيسية

- **شاشة تحميل احترافية**: رسوم متحركة جذابة عند فتح الموقع
- **هيدر ثابت**: يحتوي على:
  - شعار الصيدلية
  - شريط بحث ذكي للمنتجات
  - أزرار سريعة (الموقع، الوضع الليلي، تغيير اللغة، واتساب، السلة)
  - عداد المنتجات في السلة
- **قسم البطل (Hero Section)**:
  - عنوان رئيسي جذاب
  - وصف الخدمات
  - مميزات الصيدلية (توصيل سريع، أسعار مناسبة، خدمة 24/7)
  - زر "تسوق الآن" للانتقال للمنتجات
  - زر "استشر الدكتور AI" للتواصل مع المساعد الطبي

#### 🗂️ الفئات (Categories)
- عرض فئات المنتجات بشكل مرئي جذاب
- أيقونات مميزة لكل فئة
- الفئات المتاحة:
  - أدوية
  - فيتامينات
  - عناية شخصية
  - مستلزمات طبية
  - أعشاب طبيعية
  - منتجات الأطفال
- الضغط على أي فئة يعرض منتجاتها فقط

#### 🛍️ المنتجات (Products)

- **عرض شبكي متجاوب**: يتكيف مع جميع أحجام الشاشات
- **بطاقة منتج تحتوي على**:
  - صورة المنتج
  - اسم المنتج
  - الوصف
  - السعر
  - شارة "جديد" للمنتجات الحديثة
  - زر "أضف للسلة"
- **فلترة المنتجات**:
  - حسب الفئة
  - البحث بالاسم
  - عرض جميع المنتجات
- **تحميل تلقائي**: المنتجات تُحمل من Firebase Firestore

#### 🛒 السلة (Shopping Cart)
- **لوحة جانبية منزلقة** تظهر عند الضغط على أيقونة السلة
- **معلومات المنتج في السلة**:
  - صورة المنتج
  - الاسم والسعر
  - أزرار زيادة/نقص الكمية
  - زر حذف المنتج
- **حساب تلقائي**:
  - المجموع الفرعي
  - رسوم التوصيل (50 جنيه)
  - الإجمالي النهائي
- **زر إتمام الطلب**: ينقل للواتساب مع تفاصيل الطلب
- **حفظ السلة**: تُحفظ في localStorage حتى بعد إغلاق المتصفح

#### 📱 إتمام الطلب عبر واتساب

- عند الضغط على "إتمام الطلب":
  - يتم تجهيز رسالة واتساب تلقائية
  - تحتوي على:
    - قائمة المنتجات والكميات
    - الأسعار التفصيلية
    - الإجمالي النهائي
  - تفتح واتساب مباشرة على رقم الصيدلية: 01006273308

#### 🌙 الوضع الليلي (Dark Mode)
- تبديل سلس بين الوضع الفاتح والداكن
- حفظ التفضيل في localStorage
- تصميم متناسق في كلا الوضعين

#### 🌍 تعدد اللغات (Multi-Language)
- **اللغة العربية** (افتراضي)
- **اللغة الإنجليزية**
- تبديل فوري بين اللغتين
- ترجمة كاملة لجميع عناصر الواجهة:
  - القوائم والأزرار
  - أسماء الفئات
  - النصوص الثابتة
  - رسائل التنبيه

#### 📍 Footer (التذييل)
- **معلومات الصيدلية**:
  - الشعار والاسم
  - السنة وحقوق النشر
- **معلومات التواصل**:
  - رقم الهاتف
  - البريد الإلكتروني
  - العنوان

- **الخدمات**:
  - قائمة بالخدمات المتاحة
- **قسم المطور**:
  - بطاقة احترافية بتصميم بنفسجي موجي
  - صورة المطور
  - الاسم والوظيفة
  - روابط السوشيال ميديا (Instagram, GitHub, WhatsApp, Facebook)
  - أيقونات بألوانها الأصلية

### 2️⃣ لوحة الإدارة (Admin Panel)

#### 🔐 نظام تسجيل الدخول
- **صفحة تسجيل دخول آمنة**
- **بيانات الدخول الافتراضية**:
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin123`
- **حماية الصفحات**: لا يمكن الوصول للوحة بدون تسجيل دخول
- **حفظ الجلسة**: تبقى مسجل دخول حتى تسجيل الخروج

#### 📊 لوحة التحكم الرئيسية
- **إحصائيات فورية**:
  - إجمالي المنتجات
  - عدد الفئات
  - المنتجات المتاحة
  - المنتجات غير المتاحة
- **بطاقات ملونة** لكل إحصائية
- **أيقونات مميزة** لسهولة التعرف

#### ➕ إضافة منتج جديد

- **نموذج شامل يحتوي على**:
  - اسم المنتج (عربي وإنجليزي)
  - الوصف (عربي وإنجليزي)
  - السعر
  - الفئة (قائمة منسدلة)
  - رابط الصورة
  - حالة التوفر (متاح/غير متاح)
  - شارة "جديد" (نعم/لا)
- **معاينة فورية للصورة** عند إدخال الرابط
- **التحقق من البيانات** قبل الحفظ
- **رسائل نجاح/خطأ** واضحة
- **حفظ تلقائي** في Firebase Firestore

#### 📝 إدارة المنتجات
- **جدول شامل يعرض**:
  - صورة المنتج
  - الاسم (عربي وإنجليزي)
  - السعر
  - الفئة
  - حالة التوفر
  - شارة "جديد"
  - أزرار التحكم (تعديل/حذف)
- **بحث وفلترة**:
  - البحث بالاسم
  - الفلترة حسب الفئة
  - الفلترة حسب حالة التوفر
- **تصميم متجاوب**: يعمل على جميع الأجهزة

#### ✏️ تعديل المنتجات

- **نافذة منبثقة للتعديل**
- **تحميل تلقائي** لبيانات المنتج الحالية
- **تعديل جميع الحقول**:
  - الاسم والوصف
  - السعر
  - الفئة
  - الصورة
  - حالة التوفر
  - شارة "جديد"
- **معاينة الصورة الجديدة**
- **حفظ التعديلات** مباشرة في قاعدة البيانات

#### 🗑️ حذف المنتجات
- **رسالة تأكيد** قبل الحذف
- **حذف نهائي** من قاعدة البيانات
- **رسالة نجاح** بعد الحذف

#### 🎨 واجهة الإدارة
- **تصميم احترافي** بألوان بنفسجية
- **قائمة جانبية** للتنقل:
  - لوحة التحكم
  - إضافة منتج
  - إدارة المنتجات
  - تسجيل الخروج
- **رأس الصفحة** يحتوي على:
  - عنوان القسم الحالي
  - معلومات المستخدم
  - زر تسجيل الخروج
- **تصميم متجاوب** للموبايل والتابلت

### 3️⃣ الدكتور AI (AI Doctor Assistant)


#### 🤖 المساعد الطبي الذكي
- **مدعوم بـ Cohere AI** (موديل command-r-08-2024)
- **تخصص طبي**: متخصص في الصيدلة والطب العام
- **يجيب على**:
  - الأسئلة الطبية والصحية
  - معلومات عن الأدوية واستخداماتها
  - نصائح صحية عامة
  - أعراض الأمراض
  - العلاجات المنزلية

#### 💬 واجهة المحادثة
- **تصميم شات احترافي**:
  - رسائل المستخدم (يمين)
  - رسائل الدكتور (يسار)
  - أفاتار لكل طرف
- **مؤشر الكتابة**: نقاط متحركة أثناء انتظار الرد
- **أسئلة سريعة** للبدء:
  - ما هي أعراض نزلات البرد؟
  - ما هي فوائد فيتامين د؟
  - كيف أعالج الصداع؟
- **مربع نص ذكي**:
  - يتوسع تلقائياً مع النص
  - Enter للإرسال
  - Shift+Enter لسطر جديد

#### 💾 حفظ المحادثات
- **حفظ تلقائي** في localStorage
- **استمرار المحادثة** حتى بعد إغلاق الصفحة
- **زر مسح المحادثة** لبدء محادثة جديدة


#### ℹ️ معلومات جانبية
- **بطاقة معلومات مهمة**:
  - تنبيه: المعلومات للإرشاد فقط
  - استشر طبيبك للتشخيص الدقيق
  - لا تتناول دواء بدون وصفة
- **بطاقة الطوارئ**:
  - رقم واتساب الصيدلية
  - زر اتصال سريع

#### 🎯 مميزات الذكاء الاصطناعي
- **فهم اللغة العربية** بشكل ممتاز
- **ردود دقيقة ومفيدة**
- **نصائح طبية آمنة**
- **تحذيرات مناسبة** للحالات الخطيرة
- **أسلوب متعاطف ومهني**

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js (v14 أو أحدث)
- Firebase CLI
- حساب Firebase
- حساب Cohere AI (للدكتور AI)

### خطوات التثبيت

#### 1. استنساخ المشروع
```bash
git clone https://github.com/your-username/pharmacy.git
cd pharmacy
```

#### 2. إعداد Firebase
```bash
# تثبيت Firebase CLI
npm install -g firebase-tools

# تسجيل الدخول
firebase login

# تهيئة المشروع
firebase init
```

#### 3. إعداد قاعدة البيانات
- افتح Firebase Console
- أنشئ مشروع جديد
- فعّل Firestore Database
- أنشئ Collection باسم `products`

#### 4. إعداد الدكتور AI
- احصل على API Key من [Cohere](https://dashboard.cohere.com/api-keys)
- افتح `doctor-ai/doctor-ai.js`
- ضع API Key في المتغير `COHERE_API_KEY`

#### 5. النشر
```bash
# نشر صفحة العميل
cd pharmacy-client
firebase deploy

# نشر لوحة الإدارة
cd ../pharmacy-admin
firebase deploy
```
