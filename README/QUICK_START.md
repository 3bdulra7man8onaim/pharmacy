# 🚀 دليل التشغيل السريع - صيدلية هشام

## ⚡ تشغيل سريع (5 دقائق)

### 1. تشغيل الموقع محلياً
```bash
# تشغيل خادم محلي
python -m http.server 8000
# أو
npx serve .
```

### 2. الوصول للموقع
- **صفحة العميل**: http://localhost:8000/pharmacy-client/
- **لوحة الإدارة**: http://localhost:8000/pharmacy-admin/

### 3. بيانات الدخول للإدارة
- اسم المستخدم: `admin`
- كلمة المرور: `hisham123`

## 🔧 الإعدادات المطلوبة

### Firebase (مطلوب)
1. إنشاء مشروع Firebase
2. تفعيل Firestore
3. استبدال إعدادات Firebase في:
   - `pharmacy-admin/index.html`
   - `pharmacy-client/index.html`

### ImgBB API (مطلوب لرفع الصور)
1. إنشاء حساب على imgbb.com
2. الحصول على API Key
3. استبدال المفتاح في `pharmacy-admin/index.html`

## 📱 كيفية الاستخدام

### إضافة منتج جديد
1. دخول لوحة الإدارة
2. قسم "إدارة المنتجات"
3. "إضافة منتج جديد"
4. رفع صورة المنتج
5. حفظ

### إضافة بوستر إعلاني
1. قسم "إدارة البوسترات الإعلانية"
2. "إضافة بوستر جديد"
3. رفع صورة البوستر
4. إضافة رابط التوجيه (اختياري)
5. حفظ

### متابعة الطلبات
1. قسم "الطلبات"
2. تغيير حالة الطلب
3. حذف الطلبات المكتملة

## 🌐 النشر على الإنترنت

### Firebase Hosting
```bash
npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy
```

### Netlify
1. رفع المجلد على GitHub
2. ربط Netlify بالمستودع
3. نشر تلقائي
