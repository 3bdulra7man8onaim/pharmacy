# 🔧 حل مشاكل البوسترات - صيدلية هشام

## 🚨 المشاكل الشائعة:
- "فشل في إضافة البوستر"
- "فشل رفع الصورة"
- البوستر لا يظهر بعد الإضافة

### الحلول المحسنة:

#### 1. **اختبار النظام أولاً**
- اذهب إلى لوحة الإدارة
- افتح قسم "إدارة البوسترات الإعلانية"
- اضغط "إضافة بوستر جديد"
- اضغط زر "اختبار DB" للتأكد من Firestore
- اضغط زر "اختبار API" للتأكد من رفع الصور
- إذا نجحا الاختباران، جرب إضافة البوستر

#### 2. **فحص الكونسول**
- اضغط F12 لفتح أدوات المطور
- اذهب إلى تبويب "Console"
- جرب رفع الصورة ولاحظ الرسائل
- ستظهر رسائل مفصلة عن سبب الفشل

#### 3. **التحقق من الصورة**
- ✅ حجم الصورة أقل من 10 ميجا
- ✅ نوع الصورة: JPG, PNG, GIF, WebP
- ✅ الصورة غير تالفة

#### 4. **التحقق من الاتصال**
- ✅ اتصال إنترنت مستقر
- ✅ لا يوجد حجب لموقع ImgBB
- ✅ لا يوجد Firewall يمنع الرفع

## 🔍 رسائل الخطأ الشائعة:

### "فشل في إضافة البوستر"
**الأسباب المحتملة:**
- مشكلة في اتصال Firestore
- بيانات البوستر غير صحيحة
- مشكلة في صلاحيات قاعدة البيانات

**الحل:**
1. اضغط "اختبار DB" للتأكد من Firestore
2. تحقق من إدخال عنوان البوستر
3. تأكد من رفع الصورة أولاً

### "خطأ: قاعدة البيانات غير متصلة"
**الحل:**
- تحقق من إعدادات Firebase في `index.html`
- تأكد من تفعيل Firestore في مشروع Firebase
- راجع قواعد الأمان في Firestore

### "يرجى رفع صورة البوستر أولاً"
**الحل:**
- اختر صورة من جهازك
- اضغط "رفع الصورة" وانتظر حتى تكتمل
- تأكد من ظهور رابط الصورة في الحقل

### "مفتاح ImgBB API غير موجود"
**الحل:** تحقق من وجود API Key في `pharmacy-admin/index.html`

### "فشل الاتصال بخادم ImgBB"
**الحل:** 
- تحقق من الاتصال بالإنترنت
- جرب VPN إذا كان ImgBB محجوب
- انتظر قليلاً وأعد المحاولة

## 🛠️ خطوات الإصلاح:

### 1. تجديد API Key
```javascript
// في pharmacy-admin/index.html
window.IMGBB_API_KEY = 'YOUR_NEW_API_KEY_HERE';
```

### 2. اختبار يدوي
```javascript
// في الكونسول
testImgBBConnection();
```

### 3. رفع صورة تجريبية
- اختر صورة صغيرة (أقل من 1 ميجا)
- جرب رفعها أولاً
- إذا نجحت، جرب الصورة الأصلية

## 📞 إذا استمرت المشكلة:

### تحقق من:
1. **الكونسول**: رسائل الخطأ المفصلة
2. **Network Tab**: طلبات الشبكة
3. **ImgBB Status**: حالة خدمة ImgBB

### بدائل مؤقتة:
1. استخدم روابط صور خارجية مؤقتاً
2. رفع الصور يدوياً على ImgBB ونسخ الرابط
3. استخدام خدمة رفع أخرى

## 🔧 خطوات التشخيص المفصلة:

### 1. اختبار قاعدة البيانات
```
اضغط "اختبار DB" → يجب أن تظهر "Firestore يعمل بشكل صحيح ✔"
```

### 2. اختبار رفع الصور
```
اضغط "اختبار API" → يجب أن تظهر "الاتصال يعمل بشكل صحيح ✔"
```

### 3. إضافة البوستر
```
1. أدخل عنوان البوستر
2. ارفع الصورة وانتظر ظهور الرابط
3. اختر حالة البوستر (نشط/غير نشط)
4. اضغط "حفظ"
```

### 4. فحص الكونسول
```
F12 → Console → ابحث عن رسائل الخطأ باللون الأحمر
```
