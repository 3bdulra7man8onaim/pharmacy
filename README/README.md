# 🏥 صيدلية هشام - نظام إدارة الصيدلية

## 📋 نظرة عامة
نظام متكامل لإدارة الصيدلية يتضمن:
- **صفحة العميل**: لعرض المنتجات والطلب
- **لوحة الإدارة**: لإدارة المنتجات والطلبات والبوسترات الإعلانية

## 🚀 المميزات

### صفحة العميل
- ✅ عرض المنتجات بتصميم حديث
- ✅ البحث والفلترة حسب الفئات
- ✅ سلة التسوق والمفضلة
- ✅ طلب المنتجات عبر WhatsApp
- ✅ عرض البوسترات الإعلانية
- ✅ الوضع الليلي
- ✅ تصميم متجاوب

### لوحة الإدارة
- ✅ إدارة المنتجات (إضافة/تعديل/حذف)
- ✅ إدارة البوسترات الإعلانية
- ✅ متابعة الطلبات
- ✅ الإحصائيات
- ✅ رفع الصور وتحويلها لروابط (ImgBB API)
- ✅ حفظ البيانات في Firestore

## 🛠️ التقنيات المستخدمة
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Firebase Firestore
- **رفع الصور**: ImgBB API
- **التصميم**: CSS Grid, Flexbox, CSS Variables
- **الخطوط**: Cairo, Tajawal

## 🔧 الإعداد والتشغيل

### 1. إعداد Firebase
1. إنشاء مشروع Firebase جديد
2. تفعيل Firestore Database
3. نسخ إعدادات Firebase إلى الملفات
4. رفع قواعد Firestore من ملف `firestore.rules`

### 2. إعداد ImgBB API
1. إنشاء حساب على [ImgBB](https://imgbb.com/)
2. الحصول على API Key
3. استبدال المفتاح في `pharmacy-admin/index.html`

### 3. تشغيل الموقع
```bash
# تشغيل خادم محلي
python -m http.server 8000
# أو
npx serve .
```
