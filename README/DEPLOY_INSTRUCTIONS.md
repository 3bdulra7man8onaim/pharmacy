# 🚀 تعليمات نشر الموقع - صيدلية هشام

## 🔗 ربط الموقع المنشور بلوحة الإدارة

تم توحيد إعدادات Firebase بين صفحة العميل ولوحة الإدارة. الآن يستخدمان نفس قاعدة البيانات.

### 📋 التغييرات المطلوبة:

#### 1. **تم توحيد مشروع Firebase:**
- **المشروع الموحد:** `pharmacy-admin-2ff91`
- **صفحة العميل:** تستخدم نفس قاعدة البيانات
- **لوحة الإدارة:** تدير نفس البيانات

#### 2. **الملفات المحدثة:**
- ✅ `pharmacy-client/index.html` - إعدادات Firebase محدثة
- ✅ `pharmacy-client/.firebaserc` - مشروع موحد
- ✅ قواعد Firestore موحدة

### 🚀 خطوات إعادة النشر:

#### الطريقة 1: نشر من مجلد العميل
```bash
cd pharmacy-client
firebase deploy
```

#### الطريقة 2: نشر الموقع كاملاً
```bash
# من المجلد الرئيسي
firebase deploy --project pharmacy-admin-2ff91
```

#### الطريقة 3: نشر من Firebase Console
1. اذهب إلى [Firebase Console](https://console.firebase.google.com/)
2. اختر مشروع `pharmacy-admin-2ff91`
3. اذهب إلى Hosting
4. ارفع ملفات `pharmacy-client` يدوياً

### 🔧 التحقق من النشر:

#### 1. **اختبار الاتصال:**
```
افتح https://pharmacy-client.web.app/
اضغط F12 → Console
ابحث عن رسائل Firebase
```

#### 2. **اختبار البيانات:**
```
أضف منتج من لوحة الإدارة المحلية
تحقق من ظهوره في الموقع المنشور
```

#### 3. **اختبار البوسترات:**
```
أضف بوستر من لوحة الإدارة
تحقق من ظهوره في الموقع المنشور
```

### 📱 الآن الموقع مربوط بالكامل:

#### صفحة العميل (المنشورة):
- **الرابط:** https://pharmacy-client.web.app/
- **البيانات:** من `pharmacy-admin-2ff91`
- **المنتجات:** تظهر من لوحة الإدارة
- **البوسترات:** تظهر من لوحة الإدارة

#### لوحة الإدارة (محلية):
- **الرابط:** http://localhost:8000/pharmacy-admin/
- **البيانات:** تُحفظ في `pharmacy-admin-2ff91`
- **التحكم:** في المنتجات والبوسترات والطلبات

### 🔄 سير العمل الجديد:

1. **إضافة منتج:**
   ```
   لوحة الإدارة → إضافة منتج → يظهر في الموقع المنشور فوراً
   ```

2. **إضافة بوستر:**
   ```
   لوحة الإدارة → إضافة بوستر → يظهر في الموقع المنشور فوراً
   ```

3. **استلام طلبات:**
   ```
   العميل يطلب من الموقع → الطلب يظهر في لوحة الإدارة
   ```

### ⚠️ ملاحظات مهمة:

#### قبل النشر:
- تأكد من تشغيل `firebase login`
- تحقق من اختيار المشروع الصحيح
- اختبر الموقع محلياً أولاً

#### بعد النشر:
- اختبر جميع الوظائف
- تحقق من ظهور البيانات
- اختبر إضافة طلب جديد

### 🆘 في حالة المشاكل:

#### إذا لم تظهر البيانات:
```bash
# تحقق من المشروع المستخدم
firebase projects:list
firebase use pharmacy-admin-2ff91
```

#### إذا فشل النشر:
```bash
# إعادة تسجيل الدخول
firebase logout
firebase login
firebase deploy
```
