# 🧪 اختبار الربط بين الموقع ولوحة الإدارة

## ✅ تم توحيد المشاريع بنجاح!

### 🔗 الربط الحالي:
- **صفحة العميل:** `pharmacy-client.web.app` 
- **لوحة الإدارة:** `localhost:8000/pharmacy-admin/`
- **قاعدة البيانات:** `pharmacy-admin-2ff91` (موحدة)

### 🧪 اختبارات الربط:

#### 1. اختبار المنتجات:
```
✅ لوحة الإدارة → إضافة منتج
✅ الموقع المنشور → يظهر المنتج فوراً
✅ تحديث في الوقت الفعلي
```

#### 2. اختبار البوسترات:
```
✅ لوحة الإدارة → إضافة بوستر
✅ الموقع المنشور → يظهر البوستر فوراً
✅ تحديث في الوقت الفعلي
```

#### 3. اختبار الطلبات:
```
✅ العميل → طلب منتج من الموقع
✅ لوحة الإدارة → يظهر الطلب فوراً
✅ تحديث حالة الطلب
```

### 🚀 خطوات الاختبار:

#### الخطوة 1: تشغيل لوحة الإدارة محلياً
```bash
python -m http.server 8000
# افتح http://localhost:8000/pharmacy-admin/
```

#### الخطوة 2: إعادة نشر صفحة العميل
```bash
cd pharmacy-client
firebase deploy
```

#### الخطوة 3: اختبار الربط
```
1. أضف منتج من لوحة الإدارة
2. افتح https://pharmacy-client.web.app/
3. تحقق من ظهور المنتج
4. أضف بوستر من لوحة الإدارة
5. تحقق من ظهور البوستر في الموقع
```

### 📊 مراقبة الاتصال:

#### في لوحة الإدارة:
```
F12 → Console → ابحث عن:
✅ "تم تهيئة Firebase بنجاح"
✅ "اتصال Firestore يعمل"
```

#### في الموقع المنشور:
```
F12 → Console → ابحث عن:
✅ "Products loaded from Firestore"
✅ "Ads loaded from Firestore"
```
